🌦️ تطبيق الطقس | Weather App

موقع طقس بسيط يعرض حالة الطقس الحالية وتوقعات 5 أيام لأي مدينة في العالم، ويدعم اللغتين العربية والإنجليزية.

A simple weather website that shows current weather and a 5-day forecast for any city, with Arabic and English support.

✨ المميزات | Features
🔍 البحث عن أي مدينة بالعربية أو الإنجليزية (عبر Geocoding API)
🌡️ درجة الحرارة الحالية والإحساس الفعلي بالحرارة
💧 الرطوبة، سرعة الرياح، الضغط الجوي، والرؤية
📅 توقعات الطقس لمدة 5 أيام
🕒 عرض التاريخ والوقت المحلي للمدينة
🌍 دعم العربية والإنجليزية مع تبديل اتجاه الصفحة (RTL / LTR)
💾 حفظ آخر مدينة ولغة مفضلة في المتصفح (localStorage)
🛠️ التقنيات المستخدمة | Built With
HTML5
CSS3
JavaScript (Vanilla)
OpenWeatherMap API
